+WHAT THIS EXPERIMENT DOES
+
+The program shows the Ternus illusion. Two static images, three items each, alternate on screen. The second image is shifted sideways by one item position, so two positions overlap between the images. Nothing in either image moves, but when they follow one another you may see illusory movement. Some people see all three items travel together, which is called group motion. Others see two items stay put while the outer one jumps from side to side, which is called element motion. We record what the observer reports. There is no correct answer.
+
+There are two stimulus conditions. In DOTS the three items are identical white circles. In SHAPES they are a circle, a triangle and a square. Within a SHAPES sequence the triangle and the square keep their identities at the two overlapping positions, and the circle sits at the opposite ends. Those shapes give extra information about which item in one image aligns with which item in the next. Comparing DOTS and SHAPES therefore lets us ask whether that information changes the illusory motion perception. The condition label only says what was shown, not what the participant should answer: a DOTS trial can get either response (group or element motion), and so can a SHAPES trial.
+
+We also vary the time gap between the two images. This is the interstimulus interval, or ISI, and it takes four values: 0, 50, 500 and 1000 ms. At ISI 0 the second image replaces the first straight away. At any positive ISI the items disappear for that long and only the fixation cross stays on screen. Two stimulus types at four intervals gives eight combinations. The interval can change what you perceive, so report what you actually see rather than trying to produce a particular result.
+
+The experiment has two blocks, one for DOTS and one for SHAPES, 20 trials each, with five trials at every ISI. A full run is 40 trials and should write 40 rows in the data file. Trials are shuffled inside each block. Block order follows the participant number: odd numbers get DOTS first, even numbers get SHAPES first. That way both orders are spread across participants, so the difference between conditions is less tangled up with which one happened to come first. For your final run you will be your own participant.

+GLOSSARY
+
+Preloading: prepares stimuli ahead of presentation.
+Trial: one stimulus-response episode. Expyriment's Trial object holds the factors and stimuli.
+Block: a group of trials. Here each block holds either the DOTS trials or the SHAPES trials.
+Factor / level: a factor is a manipulated variable and a level is one of its values. Together they define the comparisons.
+Experimental condition: one combination of factor levels. Here each stimulus type is tested at each ISI.
+Full factorial: every combination of the chosen factor levels, so all the planned combinations get included.
+Randomization: varies trial order at random, which weakens systematic links between condition and trial position.
+Counterbalancing: spreads condition orders across participants, so order effects don't pile onto one condition.
+Balanced Latin square: orders that balance positions and immediate predecessors. With two blocks, that means AB and BA.
+ISI: the gap between the two stimulus frames. Changing it can change the perceived motion.
+Intertrial interval (ITI): the programmed pause between trials. Here a 500 ms blank separates successive episodes.
+Fixation cross: gives the eye a common place to look, which keeps viewing behavior consistent.
+Refresh rate: screen refreshes per second. At 60 Hz successive refreshes are about 16.7 ms apart, which constrains visual timing.
+Response coding: turns keys into labels and numbers. Consistent coding connects the action to the saved observation.
+Element / group motion: one item appearing to jump versus all of them moving together. These are the two percepts you report.
+Response time: elapsed time from a defined start to the response. Here it starts when the response prompt appears.
+Data / event files: .xpd holds the trial rows you add; event files log software events so you can inspect execution.
+Pilot: a short test of the procedure, checking presentation, responses and saving before real data collection.
+Refactoring: changing code structure while behavior stays the same, which makes later changes and checks easier.
+Git repository: the local project history kept in .git, which lets you inspect and recover committed versions.
+Staging / commit: staging picks file versions and a commit records them. Together they make a checkpoint.
+Diff / log: diff shows changes and log lists commits. Both make the development visible.

+import random
+import expyriment as xpy
+
+# Experiment initialization
+e = xpy.design.Experiment(name="Ternus experiment", background_colour=(0, 0, 0), foreground_colour=(255, 255, 255))
+e.data_variable_names = ["condition", "trial", "isi_ms", "frame_ms", "response", "group_response", "key", "rt_ms"]
+xpy.control.initialize(e)
+
+# DOTS stimuli
+list1 = []
+screen1 = xpy.stimuli.Canvas(size=(600, 300), colour=(0, 0, 0))
+xpy.stimuli.Circle(radius=20, position=(-120, -50), colour=(255, 255, 255)).plot(screen1)
+xpy.stimuli.Circle(radius=20, position=(-40, -50), colour=(255, 255, 255)).plot(screen1)
+xpy.stimuli.Circle(radius=20, position=(40, -50), colour=(255, 255, 255)).plot(screen1)
+
+screen2 = xpy.stimuli.Canvas(size=(600, 300), colour=(0, 0, 0))
+xpy.stimuli.Circle(radius=20, position=(-40, -50), colour=(255, 255, 255)).plot(screen2)
+xpy.stimuli.Circle(radius=20, position=(40, -50), colour=(255, 255, 255)).plot(screen2)
+xpy.stimuli.Circle(radius=20, position=(120, -50), colour=(255, 255, 255)).plot(screen2)
+
+# SHAPES stimuli
+screen3 = xpy.stimuli.Canvas(size=(600, 300), colour=(0, 0, 0))
+xpy.stimuli.Circle(radius=20, position=(-120, -50), colour=(255, 255, 255)).plot(screen3)
+xpy.stimuli.Shape(vertex_list=xpy.misc.geometry.vertices_regular_polygon(3, 54), position=(-40, -50), colour=(255, 255, 255)).plot(screen3)
+xpy.stimuli.Rectangle(size=(35, 35), position=(40, -50), colour=(255, 255, 255)).plot(screen3)
+
+screen4 = xpy.stimuli.Canvas(size=(600, 300), colour=(0, 0, 0))
+xpy.stimuli.Shape(vertex_list=xpy.misc.geometry.vertices_regular_polygon(3, 54), position=(-40, -50), colour=(255, 255, 255)).plot(screen4)
+xpy.stimuli.Rectangle(size=(35, 35), position=(40, -50), colour=(255, 255, 255)).plot(screen4)
+xpy.stimuli.Circle(radius=20, position=(120, -50), colour=(255, 255, 255)).plot(screen4)
+
+# Fixation cross and text screens
+thing1 = xpy.stimuli.FixCross(size=(20, 20), line_width=4, colour=(255, 255, 255))
+screen5 = xpy.stimuli.BlankScreen(colour=(0, 0, 0))
+thing1.plot(screen5)
+text1 = xpy.stimuli.TextScreen(heading="Ternus experiment", text="Keep your eyes on the central cross.\n\nLEFT = element motion\nRIGHT = group motion\n\nPress SPACE to start.")
+text2 = xpy.stimuli.TextScreen(heading="What did you see?", text="LEFT = element motion\nRIGHT = group motion")
+screen6 = xpy.stimuli.BlankScreen(colour=(0, 0, 0))
+
+# Fixation on stimulus and text screens
+thing1.plot(screen1)
+thing1.plot(screen2)
+thing1.plot(screen3)
+thing1.plot(screen4)
+thing1.plot(text1)
+thing1.plot(text2)
+
+# Preloading
+screen1.preload()
+screen2.preload()
+screen3.preload()
+screen4.preload()
+screen5.preload()
+text1.preload()
+text2.preload()
+screen6.preload()
+
+# DOTS block and trial construction
+b1 = xpy.design.Block(name="DOTS")
+b1.set_factor("condition", "DOTS")
+for v in [0, 0, 0, 0, 0, 50, 50, 50, 50, 50, 500, 500, 500, 500, 500, 1000, 1000, 1000, 1000, 1000]:
+    t = xpy.design.Trial()
+    t.set_factor("isi_ms", v)
+    b1.add_trial(t)
+
+# Randomization of DOTS trials
+for i in range(len(b1.trials) - 1, 0, -1):
+    j = random.randint(0, i)
+    b1.trials[i], b1.trials[j] = b1.trials[j], b1.trials[i]
+
+# SHAPES block and trial construction
+b2 = xpy.design.Block(name="SHAPES")
+b2.set_factor("condition", "SHAPES")
+for v in [0, 0, 0, 0, 0, 50, 50, 50, 50, 50, 500, 500, 500, 500, 500, 1000, 1000, 1000, 1000, 1000]:
+    t = xpy.design.Trial()
+    t.set_factor("isi_ms", v)
+    b2.add_trial(t)
+
+# Randomization of SHAPES trials
+for i in range(len(b2.trials) - 1, 0, -1):
+    j = random.randint(0, i)
+    b2.trials[i], b2.trials[j] = b2.trials[j], b2.trials[i]
+
+# Stimuli for DOTS trials
+for t in b1.trials:
+    t.add_stimulus(screen1)
+    t.add_stimulus(screen2)
+    t.add_stimulus(screen5)
+    t.add_stimulus(text2)
+    t.add_stimulus(screen5)
+    t.add_stimulus(screen6)
+
+# Stimuli for SHAPES trials
+for t in b2.trials:
+    t.add_stimulus(screen3)
+    t.add_stimulus(screen4)
+    t.add_stimulus(screen5)
+    t.add_stimulus(text2)
+    t.add_stimulus(screen5)
+    t.add_stimulus(screen6)
+
+# Experiment start
+e.add_block(b1)
+e.add_block(b2)
+xpy.control.start(skip_ready_screen=True)
+
+# Counterbalancing
+if e.subject % 2 == 0:
+    e.blocks.reverse()
+
+# Instructions
+text1.present()
+e.keyboard.wait(keys=[xpy.misc.constants.K_SPACE])
+
+# Trial presentation
+for b in e.blocks:
+    for t in b.trials:
+        v = t.get_factor("isi_ms")
+        t.stimuli[2].present()
+        e.clock.wait(200)
+
+        for i in range(3):
+            t.stimuli[0].present()
+            e.clock.wait(250)
+            if v > 0:
+                t.stimuli[4].present()
+                e.clock.wait(v)
+
+            t.stimuli[1].present()
+            e.clock.wait(250)
+            if v > 0:
+                t.stimuli[4].present()
+                e.clock.wait(v)
+
+        # Response collection
+        t.stimuli[3].present()
+        k, r = e.keyboard.wait(keys=[xpy.misc.constants.K_LEFT, xpy.misc.constants.K_RIGHT])
+
+        if k == xpy.misc.constants.K_LEFT:
+            a = "element"
+            g = 0
+        else:
+            a = "group"
+            g = 1
+
+        # Intertrial interval
+        t.stimuli[5].present()
+        e.clock.wait(500)
+        # Data saving
+        e.data.add([b.get_factor("condition"), t.id, v, 250, a, g, k, r])
+        e.data.save()
+
+# Experiment end
+xpy.control.end()

+"""Check a Ternus data file (.xpd) against the design described in Auxiliary.txt.
+
+Usage (from the session-03 folder, with the class Python environment):
+    python check_data.py                  # checks the newest file in data/
+    python check_data.py data/FILE.xpd    # checks a specific file
+
+It checks that the file is complete and consistent: number of rows, trials per
+condition and ISI, response coding, block order and trial numbering. It cannot
+prove that what appeared on screen matched what was saved, because the file
+only holds what the program wrote down.
+
+The expected numbers come from config.py, so a short test run (fewer trials per
+ISI in config.py) is checked against its own design.
+"""
+import csv
+import glob
+import os
+import sys
+from collections import Counter
+
+from expyriment.misc import constants
+
+import config
+
+CONDITIONS = ("DOTS", "SHAPES")
+
+EXPECTED_COLUMNS = ["subject_id", "condition", "trial", "isi_ms", "frame_ms",
+                    "response", "group_response", "key", "rt_ms"]
+
+# Written out here on purpose, separately from Ternus.py, so that this check
+# does not simply repeat whatever the experiment does.
+# raw key code -> (response, group_response) as saved in the file
+EXPECTED_CODING = {
+    str(constants.K_LEFT): ("element", "0"),
+    str(constants.K_RIGHT): ("group", "1"),
+}
+
+
+def read_xpd(path):
+    """Return the column names and the data rows (as dictionaries) of an .xpd file."""
+    with open(path, newline="") as file:
+        lines = [line for line in file if not line.startswith("#")]
+    reader = csv.DictReader(lines)
+    return reader.fieldnames, list(reader)
+
+
+def check_columns(fieldnames, rows):
+    if fieldnames == EXPECTED_COLUMNS:
+        return []
+    return [f"columns are {fieldnames}, expected {EXPECTED_COLUMNS}"]
+
+
+def check_row_count(fieldnames, rows):
+    expected = len(CONDITIONS) * len(config.ISI_VALUES_MS) * config.TRIALS_PER_ISI
+    if len(rows) == expected:
+        return []
+    return [f"{len(rows)} rows, expected {expected}"]
+
+
+def check_trials_per_condition_and_isi(fieldnames, rows):
+    problems = []
+    counts = Counter((row["condition"], row["isi_ms"]) for row in rows)
+    expected_cells = {(c, str(isi)) for c in CONDITIONS for isi in config.ISI_VALUES_MS}
+    for condition, isi in sorted(expected_cells):
+        found = counts[(condition, isi)]
+        if found != config.TRIALS_PER_ISI:
+            problems.append(f"{condition} at ISI {isi}: {found} rows, expected {config.TRIALS_PER_ISI}")
+    for condition, isi in sorted(set(counts) - expected_cells):
+        problems.append(f"unexpected combination: condition {condition!r}, ISI {isi!r}")
+    return problems
+
+
+def check_block_order(fieldnames, rows):
+    """Odd participant numbers do DOTS first, even numbers SHAPES first, one unbroken block each."""
+    subject = int(rows[0]["subject_id"])
+    expected_first = "DOTS" if subject % 2 == 1 else "SHAPES"
+    expected = [expected_first] + [c for c in CONDITIONS if c != expected_first]
+    blocks = []
+    for row in rows:
+        if not blocks or blocks[-1] != row["condition"]:
+            blocks.append(row["condition"])
+    if blocks == expected:
+        return []
+    return [f"participant {subject}: blocks appear as {blocks}, expected {expected}"]
+
+
+def check_trial_numbers(fieldnames, rows):
+    found = [row["trial"] for row in rows]
+    expected = [str(number) for number in range(1, len(rows) + 1)]
+    if found == expected:
+        return []
+    return [f"trial column is {found[:8]}..., expected 1, 2, 3, ... in order"]
+
+
+def check_frame_duration(fieldnames, rows):
+    bad = [row["trial"] for row in rows if row["frame_ms"] != str(config.IMAGE_DURATION_MS)]
+    if not bad:
+        return []
+    return [f"frame_ms differs from config.IMAGE_DURATION_MS ({config.IMAGE_DURATION_MS}) on trials {bad[:8]}"]
+
+
+def check_response_coding(fieldnames, rows):
+    """LEFT must be saved as element/0 and RIGHT as group/1."""
+    problems = []
+    for row in rows:
+        coding = EXPECTED_CODING.get(row["key"])
+        if coding is None:
+            problems.append(f"trial {row['trial']}: key {row['key']!r} is neither LEFT nor RIGHT")
+        elif (row["response"], row["group_response"]) != coding:
+            problems.append(f"trial {row['trial']}: key {row['key']} saved as "
+                            f"{row['response']}/{row['group_response']}, expected {coding[0]}/{coding[1]}")
+    return problems
+
+
+def check_reaction_times(fieldnames, rows):
+    bad = [row["trial"] for row in rows if not (row["rt_ms"].isdigit() and int(row["rt_ms"]) > 0)]
+    if not bad:
+        return []
+    return [f"missing or invalid rt_ms on trials {bad[:8]}"]
+
+
+def check_single_participant(fieldnames, rows):
+    ids = sorted({row["subject_id"] for row in rows})
+    if len(ids) == 1:
+        return []
+    return [f"rows from several participants: {ids}"]
+
+
+CHECKS = [
+    ("columns are the expected ones", check_columns),
+    ("number of rows matches the design", check_row_count),
+    ("trials per condition and ISI", check_trials_per_condition_and_isi),
+    ("one participant", check_single_participant),
+    ("block order follows the participant number", check_block_order),
+    ("trial numbers are 1, 2, 3, ... in order", check_trial_numbers),
+    ("frame_ms matches config.py", check_frame_duration),
+    ("LEFT = element/0, RIGHT = group/1", check_response_coding),
+    ("reaction times are present", check_reaction_times),
+]
+
+
+def run_checks(fieldnames, rows):
+    """Run all checks and return a list of (description, problems)."""
+    if not rows:
+        return [("file contains data rows", ["no data rows found"])]
+    return [(description, check(fieldnames, rows)) for description, check in CHECKS]
+
+
